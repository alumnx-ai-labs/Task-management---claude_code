# Task Management — Frontend

React (JavaScript, Vite) single-page app. Talks only to the backend REST API at `http://localhost:8000/api` (see `src/services/api.js`).

## Setup

```bash
npm install
```

## Run

Requires the backend to be running first (see `../backend/README.md`).

```bash
npm run dev
```

Open the printed local URL (default `http://localhost:5173`).

## Test

```bash
npm test
```

See [../specs/001-task-management/quickstart.md](../specs/001-task-management/quickstart.md) for the full validation walkthrough.
